# <h1>E-eum Project Front-Server </h1>

> 빠른 답변과 자동화에 익숙해진 세대가, <br/>
> 스스로 사고하고 문장을 짜는 힘을 기를 수 있도록 돕는 훈련 솔루션.

### 💾 프로젝트 소개

E-eum은 AI(Gemini)를 통해, 학생들이 스스로 사고하고 문장을 만들도록 돕는 **자기표현 훈련 코치** 이음입니다. 
<br />
여러가지 글 주제를 선택하여, **글쓰기 또는 말하기를** 통해 답변을 제출하고, <br />
해당 답변을 AI가 분석하여 평가를 진행합니다.
<br />

해당 답변은 국립국어원의 작문 평가 기준을 기반으로 **5가지의 피드백과, 글쓰기 MBTI 캐릭터**를 제공합니다.
<br />
해당 피드백과, MBTI를 통해 나만의 글쓰기 유형과 점수를 확인할 수 있으며, 나의 기록을 통해 성장 변화를 추적할 수 있습니다.
